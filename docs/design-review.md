## 2. 시안별 정리

### src1 · 통장 정리

- 통장 속지(기욜슈 무늬), 괘선, 표지 색 6권, 인주 도장으로 화면 전체를 짓습니다. 월급날 거래가 한 줄씩 인쇄되는 연출에만 과감함을 몰아넣었습니다.
- 지불 패널이 열리면 장면 카드가 한 줄로 접혀 선택지 자리를 대신합니다. 1366×768에서 장면과 계좌 요약이 첫 화면에 모두 들어옵니다.
- 결과는 통장 잔액표, 만기 영수증, 도장으로 마무리해 "1년 통장 정리"라는 이야기가 남습니다.
- 강점: 주제(통장 쪼개기·가계부)와 은유가 정확히 맞고, 글자가 크고 대비가 좋아 교실 프로젝터와 태블릿에서 읽기 쉽습니다.
- 위험: 레이아웃 문법은 익숙한 편이라 "게임 같다"는 인상은 셋 중 가장 약합니다. 휴대폰 지불 패널은 7개 수단이 1열로 길어집니다.

### src2 · 통장 덱

- 상단 HUD(순자산·만족도·신용점수·비상금)와 12칸 런 맵으로 "12개월 로그라이크 런"을 가장 직접적으로 표현했습니다.
- 오른쪽 통장 6장이 이번 달 변화액과 함께 붙고, 상태 효과와 예약된 장면이 별도 패널로 나옵니다.
- 결과 화면이 가장 완결적입니다. 결산, 적금 만기 표, 그래프, 가계부 비교, 선택 기록, 도전과제 13칸, 발표 모드가 모두 한 흐름에 있습니다.
- 강점: 기획서가 요구한 게임성(월별 진행, 상태, 조건부 선택지)을 가장 잘 드러냅니다. 정보 밀도가 높아 발표 자료로도 유용합니다.
- 위험: 요소가 많아 12분 수업에서 학생이 어디를 봐야 할지 흐려질 수 있습니다. 휴대폰 결과 화면이 깁니다.

### src3 · 열두 컷 인화 띠

- 잉크색 바탕 위 인화지 컷. 1~12월 띠에 지나온 달의 순자산이 막대로 현상되고, 선택을 확정하면 새 컷이 인화됩니다.
- 결과는 큰 엔딩 제목과 순자산 그래프, 핵심 선택 4개로 정리해 발표에 강합니다.
- 강점: 셋 중 가장 개성 있고 기억에 남습니다. 결과 화면의 인상이 좋아 수업 마무리 연출로 힘이 있습니다.
- 위험: 어두운 화면이라 밝은 교실 프로젝터에서 불리할 수 있고, 작은 글씨가 많습니다. 1024 태블릿 지불 패널에서 확정 버튼이 접히는 문제가 보고되었습니다.

## 3. 고르는 기준

| 상황 | 추천 |
| --- | --- |
| 교실 가독성과 주제 적합도를 우선 | src1 |
| 게임성과 정보 밀도, 발표 자료 완성도를 우선 | src2 |
| 첫인상과 결과 연출의 임팩트를 우선 | src3 |

세 시안 모두 같은 목업으로 같은 화면을 그렸으므로, 실제 앱으로 옮길 때는 고른 시안의 `srcN/src/components`와 `srcN/src/screens`를 그대로 가져가고 나머지 두 폴더는 참고용으로 남기면 됩니다.

## 4. 세 시안이 공통으로 지적한 core 보강

| 제안 | 이유 |
| --- | --- |
| `cardInstallment()` 선택자 | 할부 총액·개월·매달 납입금을 화면마다 따로 계산하고 있음 |
| `accountDeltas(state)` | 계좌별 이번 달 순변화를 세 시안이 각자 계산 |
| `PaymentPlan` 표시 포맷터 | "비상금 52만 원 + 목표 8만 원" 문구를 각자 만듦 |
| `scheduled`가 채워진 목업 | 예약 장면 예고 패널이 빈 상태로만 보임 |
| `SceneRef.origin` | 예약된 장면이 어느 선택에서 왔는지 화면이 알 수 없음 |
| 투자 `costBasis` | 부분 매도 뒤 손실 확정액 계산이 부정확 |
| 엔딩 목업 3종 추가 | 지금은 debt, balanced만 있어 나머지 칭호 화면을 확인할 수 없음 |
