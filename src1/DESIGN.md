# src1 디자인 시안: 통장 정리

> 작업 중 문서. 1단계(방향과 토큰)를 먼저 적고, 마지막에 화면별 결정과 남은 문제를 채운다.

## 1. 방향 이름과 콘셉트

**통장 정리.** 은행 ATM에 종이 통장을 넣으면 프린터 헤드가 "지이익" 하며 한 줄씩 거래 내역을 찍어 줍니다.
한국 사람이라면 누구나 아는 이 장면이 "내 돈이 어디로 갔는지 눈으로 확인하는 순간"입니다.
이 시안은 화면 전체를 종이 통장의 문법(연한 민트빛 지문 무늬 용지, 괘선 위에 찍힌 날짜·적요·입금·출금·잔액, 표지 색으로 구분되는 여러 권의 통장, 은행 인주 도장)으로 짓고,
게임의 긴장(장면 카드, 선택지, 상태 효과)은 그 통장 옆에서 벌어지는 "사건"으로 둡니다.
대담함은 한 곳에만 씁니다: 월급날 통장에 거래가 한 줄씩 인쇄되는 연출. 나머지는 금융 앱처럼 조용하고 정확하게.

## 2. 1차 계획 (스킬 방식: 토큰 먼저)

### 색 (기본 팔레트)

| 이름 | hex | 역할 |
| --- | --- | --- |
| 통장 용지 | `#EDF2EE` | 배경. 크림이 아니라 은행 통장 속지의 연한 회녹색 |
| 속지 흰색 | `#F9FBF9` | 카드·패널 면 |
| 잉크 남색 | `#18264A` | 본문, 주요 버튼 (통장 인쇄 잉크) |
| 괘선 | `#BCCAC2` | 통장의 줄, 구분선 |
| 인주 빨강 | `#B8282F` | 출금 금액, 경고(사실 정보)만. 선택지에는 쓰지 않음 |
| 입금 파랑 | `#1E4FA8` | 입금 금액 (한국 은행 앱 관례: 입금 파랑, 출금 빨강) |

계좌 6종은 통장 표지 색으로 구분하고 안내 카드, 가계부, 시뮬레이션, 결과에서 똑같이 씁니다.

| 계좌 | 표지 색 | 이유 |
| --- | --- | --- |
| 생활비 | `#D9961A` 호박색 | 매일 쓰는 체크카드, 가장 따뜻한 색 |
| 비상금 | `#1F7A8C` 청록 | 파킹통장, 차분하고 믿음직한 색 |
| 적금 | `#3D6B35` 녹색 | 매달 자라는 돈 |
| 투자 | `#6B48B5` 보라 | 오르내리는 돈, 다른 통장과 성격이 다름 |
| 목표 | `#C8507A` 장미색 | 계획된 즐거움 |
| 청약 | `#8B5E34` 갈색 | 집, 땅 |

### 서체

- 본문과 숫자: **IBM Plex Sans KR** (400/500/600/700). 은행 서식 같은 단정한 고딕이고 숫자가 또렷하다. 한국 웹의 기본값인 Pretendard·Noto Sans KR을 일부러 피했다. 숫자는 모두 `tabular-nums`.
- 제목: **Black Han Sans**. 굵고 각진 포스터 서체로 "게임 같다"는 느낌을 만든다. 화면 제목, 이벤트 제목, 엔딩 칭호에만 쓴다.
- 두 서체는 굵기와 성격이 확연히 달라 섞여도 혼동이 없다.
- 크기 단계(약 1.25배): 13 / 15 / 17 / 21 / 26 / 33 / 42 / 64 px.

### 레이아웃

시뮬레이션(노트북 1366×768) 첫 화면:

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ 하늘의 1년  [1][2][3]...[11][12 결산]   순자산  만족도  신용  비상금 N개월        │  ← 상단 띠: 월 진행 + 지표
├──────────────────────────────────────────────────┬────────────────────────────┤
│ [일상 돌발] A2  노트북에 커피를 쏟음      AI 질문 │  통장 6권 (표지 색 띠)       │
│ ┌──────────────────────────────────────────────┐ │  생활비   12만 원    +6만    │
│ │ 채널별 장면 (내레이션/메신저/문자/뉴스/앱)       │ │  비상금   52.1만 원  +26.1만  │
│ │ 공개 정보: 큰 숫자 띠                          │ │  ...                        │
│ └──────────────────────────────────────────────┘ │  남은 부채                   │
│ 선택지 2×2 (같은 크기, 같은 색, 유형 표시만 다름)  │  상태 효과 / 예약 예고         │
│                                                  │  학습용 가정 금리 안내         │
└──────────────────────────────────────────────────┴────────────────────────────┘
```

- 왼쪽 정렬이 기본. 숫자는 오른쪽 정렬(통장 잔액 칸처럼).
- 지불 패널은 선택지 자리를 대신 차지한다(장면은 위에 남아 맥락 유지).
- 월급날은 장면 자리에 통장 한 쪽이 펼쳐지고 거래 줄이 인쇄된다.

### 원칙

1. 통장은 사실, 장면은 사건. 사실(잔액, 경고, 공개 정보)은 선명하게, 선택지는 중립적으로.
2. 선택지는 모두 같은 크기·색·순서(데이터 순서). 다른 것은 `kind` 아이콘과 이름뿐.
3. 같은 계좌는 어디서나 같은 표지 색 띠로 알아본다.
4. 움직임은 월급날 인쇄 한 번, 월급 공개 카운트업 한 번. 나머지는 사용자 행동에 대한 반응만.

## 3. 계획 검토 (기본값처럼 보이는지)

- 처음 떠올린 안은 "흰 배경 + 둥근 카드 그리드 + 파란 강조색의 핀테크 대시보드"였다. 같은 요청이면 누구나 도달할 SaaS 카드 키트라서 버렸다. 계좌를 똑같은 둥근 카드로 늘어놓는 대신, 통장 표지 색 띠가 달린 "줄"로 바꿨다.
- 배경을 크림색으로 하고 싶은 유혹이 있었지만 생성형 디자인의 전형이라 통장 속지의 회녹색으로 바꿨다. 실제 은행 통장 속지 색이라 주제와도 맞는다.
- 통장 괘선은 신문형 헤어라인 레이아웃으로 흐를 위험이 있어, 괘선은 거래 내역 표(통장 쪽)에만 쓰고 나머지 구획은 면 색 차이와 여백으로 나눈다. 모서리는 위계에 따라 다르게(통장 표지 4px, 패널 10px, 휴대폰 말풍선 18px).
- 작은 데이터 라벨에 고정폭 서체를 쓰는 습관을 버리고 Plex Sans KR의 tabular-nums로 통일했다.
- 제목 위 영문 대문자 머리표, 가운뎃점으로 이은 메타 문자열, 버튼 끝 화살표를 쓰지 않는다. 이벤트 유형과 코드는 작은 배지 두 개로 나눈다.
- 번호 표시는 실제 순서가 있는 곳(수업 단계, 설문 1/7, 안내 3/6, 월 1~12, 월급날 처리 순서, 선택 기록)에만 쓴다.
