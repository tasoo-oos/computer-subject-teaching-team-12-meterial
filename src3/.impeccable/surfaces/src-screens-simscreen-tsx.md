# Surface: 12개월 시뮬레이션 (+ 같은 세계의 시작·설문·안내·가계부·결과)

Scope and mode: Operate (앱 화면). 학생이 40분 수업 안에서 혼자 진행하는 작업 화면. 시뮬레이션이 주 표면이고 나머지 5개 화면이 같은 세계를 공유한다.

Audience/job: 고등학생이 노트북·태블릿에서 매달 장면을 읽고, 선택지를 고르고, 어느 통장에서 낼지 정한다. 끝에 프로젝터로 결과를 발표한다.

Constraints: core 데이터만 사용, 선택지에 정답 힌트 금지(생김새는 kind로만), 외부 요청 금지, 1366×768 첫 화면에 장면 카드·선택지·계좌 요약.

Decision process note: 서브에이전트 실행이라 결정 페이지를 띄우지 않고 배정된 방향(후보 7)으로 진행. 경쟁 카드(스트리밍 카탈로그 벽: 관객 축, 야간 노선도: 명료성 축)는 대안으로 기록만 함.

## Direction contract

THESIS: 1년은 사진관 부스에서 찍은 열두 컷짜리 인화 띠다. 매달은 한 컷이고, 결정은 셔터다. 금융 대시보드의 카드 그리드와 게임의 HP 바를 둘 다 거부하고, 두꺼운 잉크색 프레임 안에 밝게 인화된 컷이 이어지는 "네컷 사진" 문법으로 진행과 기록을 보여 준다.

OWN-WORLD: 짙은 잉크색(따뜻한 거의 검정) 프레임 레일과 플래시처럼 하얀 인화지 면. 프레임 하단의 작은 날짜 도장(2026.02 · 하늘). 통장 6색(생활비 파랑, 비상금 주황, 적금 초록, 투자 보라, 목표 분홍, 청약 청록)은 사실 정보에만 쓰인다. Pretendard 한 서체, 숫자는 모두 tabular. 컷 모서리는 작은 반경, 프레임은 두껍고 컷 사이 간격은 일정.
